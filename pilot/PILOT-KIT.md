# SaNaSoft pilot test kit

Use this kit to test SaNaSoft with 3 to 5 colleagues who use SmartPLS but have never run fsQCA. The aim is to find where they get stuck, not to test them.

## Before the session

- Ask each participant to bring the standardised latent variable scores from one of their own SmartPLS models (CSV or Excel), and a picture of the model diagram.
- Send them the SaNaSoft link, but ask them not to try it beforehand.
- Allow 45 minutes per person. Sit beside them (or share screens) and take notes. Help only if they are stuck for more than two minutes, and note when you did.

## Tasks

Read each task aloud. Ask participants to think aloud as they work.

1. Load your latent variable scores into SaNaSoft.
2. Tell SaNaSoft about your model: the role of each variable and where the arrows go.
3. Run the first suggested analysis through to the recipes for the high result.
4. In your own words, explain what Recipe 1 means for your study.
5. Run the same analysis for the low result.
6. Run the robustness check and say whether your results are robust.
7. Copy the configuration table and the methods paragraph into a Word document.

## Questionnaire after the session

**Usability.** Rate each statement from 1 (strongly disagree) to 5 (strongly agree). These are the ten items of the System Usability Scale (Brooke, 1996).

1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.

To score: for odd items subtract 1 from the rating; for even items subtract the rating from 5; add the results and multiply by 2.5. Scores above 68 are above average; above 80 is excellent.

**Open questions**

1. Which step was hardest, and why?
2. Was any word or instruction unclear?
3. Did the suggested analyses match what you expected for your model? If not, what was different?
4. Would you trust these results enough to report them in a paper? What would increase your trust?
5. What is missing that you would need for your paper?

## After the pilot

Collect all observation sheets and questionnaires, and list every problem that at least two participants had. Those are the priorities for the next version.
